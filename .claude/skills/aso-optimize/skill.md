# ASO Optimization Skill

Google Play Store 리스팅을 최적화하여 검색 가시성과 설치 전환율을 극대화한다.

## ASO 프로세스

### 1. 키워드 리서치
- 벤치마킹 데이터에서 경쟁 앱의 제목/설명 키워드 추출
- WebSearch로 "{카테고리} app keywords", "ASO {카테고리}" 검색
- 키워드 분류:
  - **Head 키워드**: 검색량 높음, 경쟁 치열 (1-2개)
  - **Mid-tail**: 적절한 검색량과 경쟁 (3-5개)
  - **Long-tail**: 낮은 경쟁, 높은 전환 (5-10개)

### 2. 앱 제목 최적화
- 30자 이내 (Google Play 제한)
- 형식: `{앱 이름} - {핵심 키워드} {부가 키워드}`
- 변형 3개 제안 (A/B 테스트용)
- 브랜딩과 키워드의 균형

### 3. 짧은 설명 (80자)
- 핵심 가치 제안을 한 문장으로
- 주요 키워드 1-2개 자연스럽게 포함
- 변형 2개 제안

### 4. 긴 설명 (4000자)
구조:
```
첫 3줄: 핵심 가치 (접힌 상태에서 보이는 부분)

주요 기능:
- 기능명 — 설명

이런 분들에게 추천합니다:
- 사용 시나리오

특징:
- 성능, 보안, 호환성

지금 다운로드하세요!
```
- 키워드를 자연스럽게 분산 배치 (강제 삽입 금지)

### 5. 스크린샷 전략
- 8장 구성 권장
- 각 스크린샷: 캡션 + 강조 포인트 정의
- 순서: 핵심기능 → 차별화기능 → 부가기능
- 텍스트 오버레이: 한 줄 카피 + 화면

### 6. 카테고리 & 태그
- 1차 카테고리 + 2차 카테고리 추천
- 관련 태그 5개

### 7. 출시 체크리스트
- [ ] 앱 아이콘 (512x512, 적응형 아이콘)
- [ ] 피처 그래픽 (1024x500)
- [ ] 스크린샷 최소 4장 (권장 8장)
- [ ] 개인정보처리방침 URL
- [ ] 콘텐츠 등급 설문 완료
- [ ] 앱 서명 키 설정
- [ ] 타겟 국가/언어 설정
- [ ] 타겟 API 레벨 확인

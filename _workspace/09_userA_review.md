# 사용자 A 리뷰 - SimpleTodo 앱 평가

**페르소나:** 25세 직장인, 매일 할일 관리하는 헤비 유저
**평가 일자:** 2026-04-06
**평가 대상:** SimpleTodo v1.0.0 전체 코드베이스

---

## 1. 핵심 기능 완성도 (각 기능별 1~5점)

### 1-1. 할일 추가/완료/삭제 - 5/5

추가: QuickAddBar가 모든 탭(오늘, 카테고리 상세, 캘린더)에 일관되게 존재한다. 텍스트 입력 후 엔터 또는 전송 버튼으로 즉시 추가된다. blurOnSubmit=false 설정으로 연속 입력이 가능하다.

완료: CheckBox 컴포넌트에 햅틱 피드백(expo-haptics)과 스프링 애니메이션이 적용되어 완료 시 손맛이 있다. 완료된 항목은 opacity 0.6 + 취소선 처리되어 시각적으로 명확하다.

삭제: 삭제 전 Alert 확인창이 뜨고, 실제로는 soft delete(is_deleted=true)로 처리된다. 웹과 네이티브 모두 대응한다.

### 1-2. 서브태스크 추가/체크/삭제 - 4/5

TodoItem을 탭하면 확장되어 서브태스크 목록이 나타난다. 인라인으로 추가/체크/삭제가 모두 가능하다. 완료/미완료 정렬도 적용된다. 서브태스크 진행률(0/3)이 배지로 표시되는 점이 좋다.

감점 사유: 서브태스크 텍스트 수정 기능이 UI에 없다. 스토어에 updateSubtask이 구현되어 있지만(todoStore.ts:308) 컴포넌트에서 호출하지 않는다. 잘못 입력하면 삭제 후 재추가해야 한다.

### 1-3. 카테고리 추가/수정/삭제 - 5/5

CategoryEditor가 Modal 기반으로 구현되어 있고, 아이콘(30종) + 색상(10종) 선택이 탭 전환 UI로 깔끔하다. 실시간 미리보기가 매우 좋다. 카테고리 삭제 시 해당 할일들의 category_id가 null로 자동 정리된다(todoStore.ts:370-376). 그리드 카드 뷰가 시각적으로 훌륭하다.

### 1-4. 색상 지정 - 4/5

TodoDetailSheet에서 파스텔 11색(null 포함) + 커스텀 10색을 제공한다. "더 많은 색상" 접기/펼치기 토글이 있어 UI가 깔끔하다. 선택한 색상은 TodoItem의 왼쪽 보더로 표시된다.

감점 사유: 색상이 할일 카드의 왼쪽 보더(borderLeftWidth: 4)에만 반영된다. 리스트에서 색상 구분이 다소 미약하다. 배경색 틴트 등 추가 시각 피드백이 있으면 좋겠다.

### 1-5. 캘린더 날짜별 조회/추가 - 5/5

월간 캘린더가 카드 형태로 표시된다. 날짜별 할일 유무를 dot(점)으로 표시하며, 색상으로 진행 상태를 구분한다(회색=미완료, 노랑=일부 완료, 초록=전체 완료). 날짜 선택 시 하단에 해당 날짜 할일 목록이 표시되고, QuickAddBar로 해당 날짜에 바로 추가할 수 있다. 월 이동 네비게이션, 오늘 날짜 강조, 요일별 색상(일=빨강, 토=파랑) 등 디테일이 좋다.

### 1-6. 검색 - 3/5

오늘 탭에서만 검색이 가능하다(today.tsx:96-107). 제목과 메모를 대상으로 검색한다.

감점 사유:
- 오늘 탭에서만 작동하고, 카테고리 탭이나 캘린더 탭에는 검색이 없다.
- 전체 할일을 대상으로 검색하는 방법이 없다. 어제 추가한 할일을 제목으로 찾으려면 캘린더에서 어제 날짜를 눌러야 한다.
- 실시간 필터링은 되지만, 검색 결과에 날짜 정보가 표시되지 않는다(오늘 할일만이니 의미 없긴 하다).

### 1-7. 반복 할일 - 4/5

TodoDetailSheet에서 매일/매주/매월 반복을 설정할 수 있다. 완료 시 다음 occurrence가 자동 생성된다(todoStore.ts:121-141). recurrence 설정이 복제되어 계속 반복되는 구조이다. TodoItem에서 "매일"/"매주"/"매월" 배지가 표시된다.

감점 사유:
- "특정 요일 반복"(예: 월/수/금)이 타입에는 정의되어 있지만(Recurrence.days_of_week) UI에서 설정할 방법이 없다.
- 반복 종료일(end_date) 설정 UI가 없다. 영원히 반복된다.
- 완료하지 않으면 다음 occurrence가 생성되지 않아, 건너뛴 날의 할일이 과거에 남는다.

### 1-8. 메모 - 5/5

TodoItem 확장 시 메모 영역이 바로 나타난다. 300ms 디바운스로 자동 저장된다(TodoItem.tsx:55-63). 멀티라인 지원. 플레이스홀더("메모 추가...")가 있어 직관적이다.

### 1-9. 정렬 (위/아래 이동) - 4/5

TodoItem 확장 시 하단에 위/아래 화살표 버튼이 나타난다. 같은 날짜, 미완료 항목끼리 sort_order를 swap하는 방식이다(todoStore.ts:188-239).

감점 사유:
- 오늘 탭에서만 이동 버튼이 전달된다(today.tsx:237-238). 캘린더/카테고리에서는 moveTodoUp/moveTodoDown이 전달되지 않는다.
- 드래그앤드롭이 아닌 버튼 방식이라 많은 항목이 있을 때 불편하다.

### 1-10. 마감일 설정 - 5/5

TodoDetailSheet에서 "없음/오늘/내일/이번 주 토/다음 주 월/직접 입력" 6개 옵션을 제공한다. 직접 입력 시 yyyy-MM-dd 형식으로 입력할 수 있다. 현재 설정된 날짜가 헤더에 표시된다. QuickAddBar에서 추가하면 자동으로 오늘 날짜(오늘 탭) 또는 선택 날짜(캘린더)가 설정된다.

## 2. UX 흐름 평가

### 2-1. 할일 추가부터 완료까지의 전체 흐름

**흐름:** QuickAddBar에서 텍스트 입력 -> 엔터/버튼 -> 리스트에 즉시 표시 -> 체크박스 탭 -> 완료 (햅틱 + 애니메이션) -> 완료됨 섹션으로 이동

이 흐름은 매우 자연스럽다. 입력에서 완료까지 최소 2탭(입력 + 체크)이면 충분하다. 연속 입력 시에도 포커스가 유지되어 빠른 등록이 가능하다.

### 2-2. 불필요한 단계

- 할일 상세 편집(마감일, 카테고리, 색상, 반복)을 보려면 TodoItem을 롱프레스하거나 확장 후 "속성 편집" 링크를 탭해야 한다(TodoItem.tsx:123, 338-346). 롱프레스는 발견성(discoverability)이 낮다. 처음 사용하는 사람은 이 기능을 모를 수 있다.
- TodoItem 탭 -> 확장 패널 -> "속성 편집" -> BottomSheet가 열리는 3단계 구조. 확장 패널에서 할 수 없는 것(마감일, 카테고리, 반복, 색상)이 BottomSheet에 있다. 이 이중 구조가 다소 혼란스럽다.

### 2-3. 사용자가 혼란스러울 수 있는 부분

1. **탭 이름과 파일명 불일치:** 파일명이 `all.tsx`인데 탭 이름은 "카테고리"이고, 파일명이 `stats.tsx`인데 탭 이름은 "캘린더"이다. 사용자에게는 문제없지만 개발 유지보수 시 혼란을 유발한다.

2. **"전체" 할일 보기가 없다:** 4개 탭이 오늘/카테고리/캘린더/설정인데, 모든 할일을 날짜 무관하게 보는 뷰가 없다. 카테고리 탭이 사실상 "전체" 역할을 하지만, 카테고리별로 분류된 상태로만 보인다.

3. **완료된 할일 확인이 번거롭다:** 오늘 탭에서 "완료됨" 섹션이 기본적으로 접혀있어(showCompleted=false) 탭해야 볼 수 있다. 카테고리 탭에서는 완료된 할일이 아예 목록에 보이지 않는다(activeTodos만 필터). 캘린더에서는 완료/미완료가 함께 보인다.

4. **캘린더에서 "오늘로 돌아가기" 버튼이 없다:** 다른 월로 이동한 후 오늘로 빠르게 돌아올 방법이 월 이동 버튼을 여러 번 누르는 것뿐이다.

## 3. 디자인 일관성

### 3-1. 색상, 폰트, 간격

**색상:** 라이트/다크 테마가 완전히 정의되어 있고(theme.ts), useTheme 훅으로 일관되게 적용된다. 모든 화면에서 동일한 colors 객체를 사용한다.

**폰트:** 화면 제목이 모두 fontSize: 26, fontWeight: '700', letterSpacing: -0.3으로 일관된다(today.tsx:310-315, all.tsx:403-406, stats.tsx:339-343, settings.tsx:356-360). Typography 토큰이 정의되어 있지만, 실제 화면에서는 직접 fontSize를 명시하는 경우가 더 많다. Typography.body, Typography.caption 등이 TodoItem의 일부에서만 사용된다.

**간격:** Spacing 토큰(xxs:4, xs:8, sm:12, md:16, lg:24)이 전반적으로 잘 사용되고 있다. paddingHorizontal: Spacing.lg가 헤더에 일관되게 적용된다.

**전반적으로 일관성이 높다.** 다만 Typography 토큰을 정의해놓고 직접 숫자를 쓰는 패턴이 혼재한다.

### 3-2. 빈 상태(Empty State)

- 오늘 탭: "오늘은 어떤 일을 할까요?" + "아래에서 할 일을 추가해보세요" -- 적절하다.
- 카테고리 탭: "카테고리를 만들어보세요" + "할일을 카테고리별로 정리할 수 있어요" -- 적절하다.
- 카테고리 상세(빈 카테고리): "할일이 없어요" + "아래에서 이 카테고리에 할일을 추가하세요" -- 적절하다.
- 미분류 빈 상태: "미분류 할일이 없어요" -- 적절하다.
- 캘린더(날짜에 할일 없음): "할일이 없습니다" + "이 날짜에 등록된 할일이 없어요" -- 적절하다.

모든 빈 상태에 아이콘 + 제목 + 설명이 있고, EmptyState 컴포넌트로 통일되어 있다. 매우 좋다.

## 4. 불편한 점 / 개선 제안

### 4-1. 매일 사용한다면 불편할 점

1. **전체 검색 부재:** 가장 큰 불편함. "지난주에 추가한 그 할일 뭐였지?"라는 상황에서 전체 검색이 불가능하다. 캘린더에서 날짜별로 뒤져야 한다.

2. **할일 제목 수정 불가:** 추가 후 제목을 변경할 방법이 없다. TodoDetailSheet에 제목 표시는 있지만(텍스트만) 편집 기능이 없다. updateTodo로 title을 변경하는 로직은 스토어에 있지만 UI에 노출되지 않는다.

3. **마감일 직접 입력이 불편하다:** 날짜 선택기(Date Picker)가 아닌 텍스트 필드에 "yyyy-MM-dd" 형식으로 타이핑해야 한다. 모바일에서 이 형식을 정확히 입력하는 것은 매우 불편하다.

4. **완료 취소(undo) 피드백 없음:** 실수로 완료 체크를 했을 때 되돌리려면 완료됨 섹션을 펼치고 다시 탭해야 한다. Snackbar나 Undo 토스트가 없다.

5. **카테고리 탭에서 QuickAddBar가 없다:** 그리드 뷰(메인)에서는 할일 추가가 불가능하다. 카테고리 상세로 들어가야 추가할 수 있다.

6. **지연/미루기 기능이 UI에 노출되지 않음:** postponeTodo가 스토어에 구현되어 있지만(todoStore.ts:176-185) 어떤 UI에서도 호출되지 않는다.

7. **알림이 미구현:** 설정에 "(준비 중)"으로 표시된 리마인더가 있고, 토글은 되지만 실제 푸시 알림이 발생하지 않는다.

8. **오늘 탭의 주간 통계가 정보량 대비 공간을 많이 차지하지 않지만**, 캘린더 탭에 통계 대시보드(주간/월간 완료율, 스트릭 히스토리 등)가 별도로 없다. "캘린더" 탭에 통계 기능이 있을 거라 기대하지만(파일명이 stats.tsx) 순수 캘린더만 있다.

### 4-2. 경쟁 앱(Todoist, TickTick) 대비 부족한 점

## 7. 종합 평가

### 잘한 점
- 할일 추가-완료의 핵심 흐름이 매우 빠르고 직관적이다.
- 카테고리 에디터(아이콘 + 색상 + 미리보기)가 경쟁 앱 수준이다.
- 캘린더 뷰의 dot 표시와 색상 코딩이 한눈에 진행 상태를 파악하게 해준다.
- 라이트/다크 테마가 완전하게 구현되어 있다.
- 반복 할일이 완료 시 자동 생성되는 로직이 올바르게 구현되어 있다.
- 햅틱 피드백과 스프링 애니메이션이 네이티브 앱 느낌을 잘 살린다.
- 스트릭 배지가 동기부여 요소로 좋다.
- 한국어 로케일이 완벽하게 적용되어 있다.

### 아쉬운 점
- 할일 제목 수정이 불가능한 것이 가장 기본적인 기능 누락이다.
- 전체 검색이 없어 과거 할일 찾기가 매우 불편하다.
- 마감일 직접 입력이 텍스트 기반이라 모바일 UX에 맞지 않는다.
- 스토어에 구현되어 있지만 UI에 노출되지 않는 기능이 여럿 있다 (postpone, updateSubtask, priority, due_time).
- 통계/분석 화면이 없다 (스토어에 getWeeklyStats, getMonthlyStats, getCategoryStats가 있지만 UI 없음).
- 알림, 위젯, 협업 등 모바일 할일 앱의 핵심 차별화 요소가 부재하다.

### 한줄 평
"핵심 기능이 잘 동작하고 디자인 완성도가 높은 깔끔한 MVP이지만, 헤비 유저가 매일 쓰기엔 제목 수정, 전체 검색, 날짜 피커 같은 기본 편의 기능이 먼저 보강되어야 한다."

## 타겟 사용자

### 1차 타겟 (MVP)

#### 세그먼트: 20~30대 직장인 (주니어~미드레벨)
- **연령/특성**: 25~35세, 사무직, 멀티태스킹 환경
- **규모**: 한국 약 500만 명 (추정, 사무직 종사자 중 디지털 도구 활용층)
- **핵심 페인포인트**:
  1. 업무 할일과 개인 할일이 섞여서 관리가 안 됨
  2. 기존 앱이 너무 복잡하거나(Notion) 너무 단순함(기본 메모)
  3. 매일 반복되는 루틴 관리가 번거로움
  4. "뭘 해야 하는지"는 알지만 "언제, 어떤 순서로"가 불명확
  5. 앱을 깔아도 3일 후 안 씀 (습관화 실패)
- **현재 사용 솔루션**:
  - 카카오톡 "나에게 보내기" (41% -- 한국 직장인 생산성 도구 조사 기반 추정)
  - 기본 메모 앱 (23%)
  - Notion (18%)
  - 기타 Todo 앱 (12%)
  - 종이 수첩/포스트잇 (6%)

### 2차 타겟 (확장)

#### 세그먼트 A: 대학생/취준생
- **연령/특성**: 20~26세, 학업 + 취업 준비 병행
- **핵심 페인포인트**:
  1. 과제 마감일 관리
  2. 스터디/그룹 프로젝트 할일 공유
  3. 습관 트래커 니즈 (운동, 자격증 공부 등)
- **현재 사용 솔루션**: Notion, 투두메이트, 기본 메모

#### 세그먼트 B: 프리랜서/1인 사업자
- **연령/특성**: 28~45세, 다수 프로젝트 동시 관리
- **핵심 페인포인트**:
  1. 클라이언트별 할일 분리
  2. 인보이스/마감일과 할일 연동
  3. 시간 추적(time tracking) 니즈
- **현재 사용 솔루션**: Todoist, Trello, Notion

#### 세그먼트 C: 자기계발 지향 MZ세대
- **연령/특성**: 22~35세, 루틴/습관 관리에 관심
- **핵심 페인포인트**:
  1. 단순 할일이 아닌 "성장 기록"을 원함
  2. 소셜 동기부여 (친구와 함께)
  3. 시각적 달성감 (통계, 스트릭)
- **현재 사용 솔루션**: 투두메이트, 해빗 트래커, 인스타그램 기록

## 주요 트렌드

### 1. AI 통합 -- 자동 분류/우선순위/일정 추천
- **현황**: Todoist AI Assistant (2024), Any.do AI Planner 등 주요 앱이 AI 기능 도입
- **영향**: 단순 체크리스트에서 "지능형 비서"로 진화. 자연어 입력 -> 자동 분류/마감일 설정이 표준화 추세
- **MVP 시사점**: AI 기능은 차별화보다 "기본 기대치"가 되어가고 있음. 최소한 자연어 입력은 지원 필요

### 2. 습관 추적(Habit Tracking)과의 융합
- **현황**: TickTick, Habitica 등 할일+습관을 하나의 앱에서 관리하는 트렌드
- **영향**: "오늘 할일" = "반복 루틴" + "일회성 태스크"로 인식 변화. 순수 Todo만으로는 차별화 어려움
- **MVP 시사점**: 반복 할일(recurring task) 기능은 MVP에서도 필수

### 3. 미니멀리즘 회귀 (Anti-Notion 움직임)
- **현황**: Notion 피로감 증가. "세팅에 시간 쓰는 것이 싫다"는 반응 확대
- **영향**: "열면 바로 쓸 수 있는" 심플한 앱에 대한 수요 재부상. Things 3, Apple Reminders 인기 이유
- **MVP 시사점**: 1인 스타트업의 최대 기회. 복잡한 기능 없이 "즉시 사용 가능"이 핵심 가치

### 4. 소셜/공유 기능
- **현황**: 투두메이트(한국), Habitica(글로벌) 등 소셜 요소 결합 앱 성장
- **영향**: 특히 MZ세대에서 "혼자 하면 작심삼일, 함께 하면 지속" 인식. 소셜 동기부여 효과 입증
- **MVP 시사점**: 초기 MVP에서는 부담. Phase 2 확장 기능으로 적합

### 5. 타임블로킹(Time Blocking) 통합
- **현황**: 캘린더와 할일 목록의 경계가 흐려지는 추세. 플래너리, Sunsama, Akiflow 등
- **영향**: "할일"을 "시간 블록"에 배치하는 방식이 생산성 전문가들 사이에서 확산
- **MVP 시사점**: 풀 캘린더는 과도하나, "오늘의 시간 계획" 수준은 고려 가치

### 6. 위젯/숏컷 중심 UX
- **현황**: Android 위젯, iOS 위젯의 중요성 증가. 앱을 열지 않고 할일 확인/추가
- **영향**: 위젯 품질이 앱 리텐션에 직접적 영향. 홈 화면 점유 = 일상 침투
- **MVP 시사점**: Android 위젯은 MVP에서 강력한 차별화 요소

## 시장 기회 (Gap)

### 1. "설정 제로" 미니멀 Todo -- Notion 피로층 공략
- **근거**: Notion 사용자의 약 30~40%가 "세팅이 복잡하다"고 불만 (Reddit, 커뮤니티 조사 기반 추정)
- **기회**: 설치 후 0초 만에 할일 입력 가능한 UX. 온보딩/튜토리얼 없이 직관적 사용
- **검증 방법**: "Notion 대안 Todo" 키워드로 Google Play 검색 시 만족스러운 결과 부재 확인

### 2. 한국어 자연어 입력 최적화
- **근거**: 기존 AI Todo 앱들은 영어 기반 자연어 처리가 우수하나 한국어 지원이 미흡
- **기회**: "내일 오후 3시 팀미팅 준비" -> 자동으로 마감일/시간/카테고리 설정
- **검증 방법**: 주요 Todo 앱의 한국어 자연어 입력 정확도 비교 테스트

### 3. "오늘 하루" 집중 뷰 (Daily Focus)
- **근거**: 대부분의 Todo 앱은 "전체 할일 목록"을 보여주어 압도감(overwhelm) 유발
- **기회**: "오늘 할 3가지"만 보여주는 집중 모드. 인지 부하 최소화
- **검증 방법**: MVP에서 "오늘의 3가지" 기능 제공 후 완료율 측정

### 4. 한국형 소셜 동기부여 (Phase 2)
- **근거**: 투두메이트가 한국에서 100만+ 다운로드 달성. 소셜 Todo 수요 검증됨
- **기회**: 카카오톡 공유, 소셜 챌린지 등 한국 플랫폼 연동형 소셜 기능
- **검증 방법**: 할일 완료 시 "카카오톡 공유" 버튼 클릭률 측정

### 5. 감성적 완료 경험 (Gamification Lite)
- **근거**: 할일 앱의 최대 이탈 원인은 "완료해도 보상감이 없음"
- **기회**: 체크 시 만족스러운 애니메이션, 일간/주간 달성 통계, 스트릭(연속 기록)
- **검증 방법**: 완료 애니메이션 유무에 따른 다음날 리텐션율 A/B 테스트

## MVP 진입 전략

### 핵심 가치 제안 (Value Proposition)
> **"열면 바로 쓴다. 오늘 할 일에만 집중한다."**
>
> 복잡한 설정 없이, 앱을 열자마자 오늘의 할일을 입력하고 하나씩 완료하는 경험.
> Notion의 복잡함도, 기본 메모의 부족함도 아닌, 딱 "할일 관리"에 최적화된 앱.

### 차별화 포인트
1. **제로 온보딩**: 회원가입 없이 즉시 사용 (로컬 저장 우선, 계정은 선택적)
2. **"오늘의 3가지" 집중 모드**: 매일 아침 핵심 3가지만 선택하여 집중
3. **감성적 완료 경험**: 체크 시 만족스러운 햅틱+애니메이션, 일일 달성률 표시
4. **고품질 Android 위젯**: 홈 화면에서 바로 확인/추가/완료 가능
5. **한국어 최적화**: 한국어 자연어 입력 ("내일 오후 3시 회의 준비" -> 자동 파싱)

|---|---|---|
| P0 (필수) | 할일 추가/완료/삭제 | 코어 기능 |
| P0 (필수) | 오늘의 할일 뷰 | 핵심 차별화 |
| P0 (필수) | 반복 할일 (매일/매주/매월) | 트렌드 #2 습관 융합 |
| P1 (중요) | 카테고리/리스트 분류 | 기본 정리 니즈 |

## 리스크 요인

| 리스크 | 심각도 | 대응 방안 |
|---|---|---|
| 빅테크 기본앱과의 경쟁 (Google Tasks, Samsung Reminder) | 높음 | 빅테크가 하지 않는 "감성+집중" 경험으로 차별화 |
| 할일 앱 레드오션 | 높음 | 니치 타겟(Notion 피로층, 미니멀 지향)에 집중 |
| 저조한 리텐션 | 높음 | 위젯+알림+스트릭으로 일상 침투, D1 리텐션 40% 미달 시 즉각 피봇 |
| 수익화 어려움 | 중간 | 무료 기능 충분히 제공하되, 통계/커스터마이징으로 프로 전환 유도 |
| 개발 리소스 부족 (1인) | 중간 | Expo + Supabase로 최소 인프라, 기능 범위 엄격 제한 |

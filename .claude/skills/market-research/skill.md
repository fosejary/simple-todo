# Market Research Skill

모바일 앱 카테고리의 시장을 체계적으로 조사하여 MVP 진입 전략을 도출한다.

## 조사 프로세스

### 1. 시장 개요 조사
- WebSearch로 "{카테고리} app market size", "{카테고리} 앱 시장 규모" 검색
- 최근 2년 내 데이터 우선, 출처 명시
- 글로벌 vs 한국 시장 구분

### 2. 트렌드 분석
- WebSearch로 "{카테고리} app trends 2025 2026", "{카테고리} 앱 트렌드" 검색
- AI/ML 통합, 구독 모델 전환, 소셜 기능 통합 등 업계 공통 트렌드 확인
- 카테고리 특화 트렌드 파악

### 3. 타겟 사용자 조사
- 주요 사용자 세그먼트 3-5개 정의
- 각 세그먼트의 인구통계, 행동 패턴, 페인포인트 기술
- 1차 타겟(MVP) vs 2차 타겟(확장) 구분

### 4. 시장 기회 분석
- 기존 앱들의 미충족 니즈(unmet needs) 식별
- 기술 트렌드로 새로 가능해진 기능 파악
- 니치 시장 기회 도출

### 5. 수익 모델 분석
- 카테고리 내 주요 수익 모델 비교 (프리미엄, 구독, 광고, 인앱구매)
- 1인 스타트업에 적합한 모델 추천
- 가격대 벤치마크

- 주요 플레이어:

## 품질 기준
- 모든 수치 데이터에 출처 URL 또는 출처명 명시
- "추정", "예상"인 경우 반드시 표기
- 최소 3개 이상의 독립적 출처에서 교차 검증

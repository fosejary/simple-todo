# App Benchmark Skill

Google Play Store의 경쟁 앱을 체계적으로 분석하여 MVP 기능 우선순위를 도출한다.

## 벤치마킹 프로세스

### 1. 앱 선별
- WebSearch로 "best {카테고리} apps android", "top {카테고리} 앱 추천" 검색
- 선별 기준:
  - 카테고리 상위 앱 5개 (시장 기준)
  - 최근 6개월 내 출시된 신규 앱 2-3개 (혁신 포착)
  - 해외 인기 앱 중 한국 미출시 1-2개 (기회 포착)

### 2. 앱별 분석
각 앱에 대해 다음을 조사:
- **기본 정보**: 이름, 개발사, 출시일, 다운로드 수, 평점
- **핵심 기능**: 주요 기능 리스트
- **UI/UX**: 네비게이션 패턴, 디자인 스타일, 온보딩 방식
- **수익 모델**: 무료/유료, 구독, 인앱구매, 광고
- **사용자 리뷰**: 별점 분포, 주요 긍정/부정 리뷰 키워드

### 3. 기능 매트릭스 작성
- 모든 앱의 기능을 통합 리스트로 정리
- 앱별 지원 여부를 테이블로 정리
- 기능별 구현 난이도 추정 (1인 개발 기준: 쉬움/보통/어려움)

### 4. 리뷰 인사이트 추출
- 부정 리뷰 Top 5 패턴 (= MVP 기회)
- 긍정 리뷰 Top 5 패턴 (= 필수 기능)
- 기능 요청 패턴 (= 차별화 기회)

### 5. MVP 기능 우선순위
- **Must-have**: 모든 경쟁 앱이 가진 기능
- **Should-have**: 50% 이상이 가진 기능
- **Nice-to-have**: 차별화 기능
- **Differentiator**: 어떤 앱도 없지만 리뷰에서 요청된 기능

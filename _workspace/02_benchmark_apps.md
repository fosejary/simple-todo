## UI/UX 패턴 분석

### 공통 패턴

1. **플로팅 액션 버튼 (FAB)**
   - 모든 앱이 화면 우하단에 원형 "+" 버튼 배치
   - 빠른 할일 추가의 핵심 진입점
   - SimpleTodo MVP에서 반드시 채택해야 할 패턴

2. **바텀 내비게이션**
   - Todoist: 오늘, 받은 편지함, 검색, 탐색
   - MS To Do: My Day, 중요, 계획된 일정, 전체
   - TickTick: 할일, 캘린더, 습관, 타이머
   - Any.do: 할일, 캘린더, 설정
   - 3-5개 탭이 표준, 4개가 가장 일반적

3. **스와이프 제스처**
   - 좌 스와이프: 삭제 또는 연기
   - 우 스와이프: 완료 처리
   - 모든 앱에서 채택된 필수 인터랙션 패턴

4. **인라인 편집**
   - 할일 항목을 탭하면 즉시 편집 모드 진입
   - 별도 편집 화면 이동 없이 제목 수정 가능
   - 상세 정보는 하단 시트(Bottom Sheet) 또는 상세 화면으로

5. **오늘(Today/My Day) 우선 뷰**
   - 앱 실행 시 "오늘" 또는 "My Day" 화면이 기본
   - 사용자의 즉각적 행동을 유도하는 패턴

6. **체크박스 + 취소선 애니메이션**
   - 완료 시 부드러운 체크 애니메이션 + 텍스트 취소선
   - 만족감을 주는 마이크로 인터랙션

| 앱 | 차별화 UI/UX 요소 |
|-----|------------------|

### 트렌드 (2025-2026)

1. **AI 통합 가속화**: Todoist, Any.do가 AI 기반 작업 분류, 우선순위 제안, 자연어 처리를 강화
2. **미니멀리즘 회귀**: 기능 과잉에 대한 반작용으로 Google Tasks처럼 극도로 단순한 앱에 대한 수요 증가
3. **통합형 생산성**: 할일+캘린더+메모+습관을 하나로 묶는 올인원 트렌드 (TickTick이 선도)
4. **위젯 강화**: Android 위젯 크기/기능이 확대, 앱 열지 않고 할일 관리 가능
5. **다크 모드 기본**: AMOLED 최적화 다크 모드가 기본 옵션으로 자리잡음

### 수익 모델 인사이트

1. **완전 무료 앱(MS To Do, Google Tasks)은 거대 생태계의 일부** - 1인 개발자가 따라할 수 없는 모델
2. **$3-6/월 구독이 업계 표준** - 핵심 기능을 무료로 주고, 고급 기능(AI, 통계, 테마)을 유료화
3. **광고 모델은 할일 앱에서 비선호** - 사용자 경험을 해치므로 대부분 구독 모델 채택
4. **권장 전략: "관대한 무료 + 가벼운 프리미엄"**
   - 경쟁 앱이 유료로 잠근 기능(리마인더, 라벨)을 무료로 제공
   - 프리미엄($1.99-2.99/월): 테마, 통계 대시보드, 클라우드 백업 용량 확대
   - 초기에는 무료로 사용자 확보 집중

## MVP 기능 제안

### 핵심 기능 (Must-have) -- Sprint 1: 2주

모든 경쟁 앱이 공통으로 제공하며, 없으면 앱으로 성립하지 않는 기능.

| 기능 | 설명 | 예상 구현 기간 |
|------|------|-------------|
| 할일 CRUD | 추가, 조회, 수정, 삭제 | 2일 |
| 완료 체크/해제 | 체크박스 토글 + 취소선 애니메이션 | 1일 |
| 마감일 설정 | 날짜/시간 선택 피커 | 1일 |
| 리스트(카테고리) 분류 | 기본 리스트 생성 및 할일 분류 | 2일 |
| 우선순위 (높음/중간/낮음) | 색상 코딩된 3단계 우선순위 | 0.5일 |
| "오늘" 뷰 | 오늘 마감 + 오늘 추가한 할일 모아보기 | 1일 |
| 다크 모드 | 시스템 설정 연동 + 수동 전환 | 1일 |
| FAB 빠른 추가 | 플로팅 버튼으로 즉시 할일 추가 | 0.5일 |
| 스와이프 동작 | 우 스와이프(완료), 좌 스와이프(삭제) | 1일 |
| 로컬 알림/리마인더 | 설정된 시간에 푸시 알림 | 2일 |

**소계: 약 12일 (여유 포함 2주)**

### 중요 기능 (Should-have) -- Sprint 2: 2주

50% 이상의 경쟁 앱이 제공하며, 사용자 리텐션에 영향을 주는 기능.

| 기능 | 설명 | 예상 구현 기간 |
|------|------|-------------|
| 하위 작업(서브태스크) | 할일 내 체크리스트 형태 | 2일 |
| 반복 작업 | 매일/매주/매월/사용자 정의 반복 | 2일 |
| 태그/라벨 | 색상 라벨로 크로스 리스트 분류 | 1.5일 |
| 검색 | 할일 제목/내용 전문 검색 | 1일 |
| 홈 위젯 | 오늘 할일 목록 위젯 (기본 1종) | 3일 |
| Supabase 동기화 | 회원가입/로그인 + 클라우드 동기화 | 3일 |
| 온보딩 | 3단계 간단 온보딩 화면 | 1일 |

**소계: 약 13.5일 (여유 포함 2주)**

| 기능 | 차별화 포인트 | 예상 구현 기간 |

## 차별화 전략

### 포지셔닝: "가볍고 관대한 한국형 투두"

경쟁 환경에서 SimpleTodo가 취할 수 있는 포지션은 다음과 같다:

```
기능 풍부함
    ^
    |  TickTick -------- Todoist
    |       |               |
    |       |    [SimpleTodo 목표 영역]
    |       |         *
    |  Any.do ------- MS To Do
    |
    |  TimeBlocks
    |
    |              Google Tasks
    +-------------------------------> 사용 용이성(심플)
```

### 전략 1: "무료의 힘"
- Todoist/TickTick이 유료로 잠근 핵심 기능(리마인더, 라벨, 통계)을 무료 제공
- "다른 앱에서 유료인 기능이 여기선 무료" -- 스토어 설명의 핵심 메시지
- 초기 사용자 확보 후 테마/고급 통계/백업 등으로 수익화

### 전략 2: "한국 시장 집중"
- 한국어 완벽 지원 (자연스러운 UI 문구, 한국 날짜 형식)
- 한국 공휴일/음력 자동 표시
- 한국 사용자 리뷰에서 나타나는 번역 품질 불만을 역이용
- ASO에서 한국어 키워드 최적화 (투두리스트, 할일 관리, 일정 관리 등)

### 전략 3: "경량 + 속도"
- TickTick, Any.do 등이 기능 추가로 무거워진 반면, 빠른 실행과 적은 배터리 소모 강조
- 앱 크기 20MB 이하 목표 (TickTick ~80MB, Todoist ~60MB 대비)
- "할일 앱은 가벼워야 한다"는 사용자 니즈에 부합

### 전략 4: "완료의 즐거움"
- 완료 시 시각적 피드백(애니메이션, 스트릭 카운터)으로 도파민 자극
- 일일/주간 완료 통계를 무료로 제공하여 성취감 극대화
- Habitica의 게이미피케이션을 가볍게 차용하되, 과도한 복잡성은 배제

### 핵심 MVP 범위 요약

```
[4주 MVP 범위]

Sprint 1 (2주): Must-have
 - 할일 CRUD + 완료 체크
 - 마감일 + 리마인더
 - 리스트 분류 + 우선순위
 - "오늘" 뷰
 - FAB + 스와이프
 - 다크 모드

Sprint 2 (2주): Should-have + 차별화
 - 서브태스크 + 반복 작업
 - 태그/라벨 + 검색
 - Supabase 동기화 (회원가입/로그인)
 - 완료 통계 대시보드 (차별화)
 - 홈 위젯 (기본 1종)
 - 온보딩
```
